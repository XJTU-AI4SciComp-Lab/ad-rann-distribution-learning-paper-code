# Results

This directory stores numerical outputs generated by scripts in `experiments/`.

Results should be organized by experiment, for example:

```text
results/
  poisson_2d/
  activation_experiment/
  nonlinear_sharp_layer/
  burgers_deeponet/
```

Typical outputs include MATLAB `.mat` files, summary `.csv` files, checkpoints, error tables, and runtime information.

Large generated results are not committed to Git. Run the corresponding script under `experiments/` to regenerate them. The saved result data can then be loaded by plotting scripts to create figures under `figures/`.
